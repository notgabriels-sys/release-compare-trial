# Release Compare evaluation trial

Release Compare 0.1.1 — 14 October 2026 print correction.

A free evaluation prototype for comparing metadata and executable architectures between two macOS plug-in bundle containers. Requires macOS and Python 3.9+. Download the attached release-compare-0.1.1-private-trial.zip from the release, extract it, and open START_HERE.md. The ZIP includes source, instructions and a labelled synthetic example.

You may run the included source locally to evaluate it on your own builds. No paid support or commercial licence is being offered. Your plug-in files stay on your machine. The tool does not run plug-ins or installers, establish DAW compatibility, or assess sound. Missing observations remain UNKNOWN. Explicit-path terminal use is verified; native Finder selection and automatic browser opening remain unverified end to end.
